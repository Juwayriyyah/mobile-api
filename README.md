# Mobile API Backend

## Description
This is a backend API built with Node.js and Express. It performs CRUD operations using MongoDB Atlas.

## Features
- Create users
- Read users
- Update users
- Delete users

## Technologies Used
- Node.js
- Express
- MongoDB Atlas
- Mongoose

## API Endpoints
- GET /users
- POST /users
- PUT /users/:id
- DELETE /users/:id
